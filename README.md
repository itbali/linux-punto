# linux-punto

Punto Switcher для Linux (X11 / KDE Plasma). Один фоновый демон на чистом
Python — без pip, без сборки, без xdotool.

## Что делает

По глобальному хоткею (по умолчанию **Pause**):

- **Есть выделенный текст** → перекодирует его по раскладке и заменяет
  выделение. `ghbdtn → привет`, `Hello → Руддщ`, и обратно.
- **Ничего не выделено** → переключает системную раскладку на следующую
  (через KDE D-Bus, индикатор в трее обновляется).

## Установка

```bash
./install.sh
```

Скрипт пропишет автозапуск в KDE и сразу запустит демон. Зависимости
(`xclip`, `python3-dbus`, `libX11`/`libXtst`) уже есть в стандартном
Ubuntu/Kubuntu — ставить ничего не нужно.

## Использование

1. Выдели текст, набранный не в той раскладке.
2. Нажми **Pause** — текст исправится на месте.
3. Без выделения **Pause** просто переключает раскладку.

## Иконка в трее

Рядом с часами появляется иконка с текущей раскладкой (`EN`/`RU`):

- **ЛКМ** — переключить раскладку;
- **ПКМ** — меню: вкл/выкл свитчер, переключить раскладку,
  **История исправлений…**, **Статистика…**, **Настройки…**, выход.
- Серая иконка = свитчер выключен, синяя = включён.
- При переключении всплывает **бейдж** с раскладкой (`RU`/`EN`) **у каретки**
  (через AT-SPI), а где позиция недоступна (терминалы, приложения без a11y) —
  у курсора мыши. Отключается в настройках.

Если включены уведомления — при переключении показывается тост с названием
языка (`Раскладка → Russian`), при исправлении — `было → стало`.

## История исправлений

Меню трея → **История исправлений…**. Список последних замен (`ghbdtn → привет`),
хранится на диске (`~/.config/punto-switcher/history.json`) и переживает
перезапуск. Для каждой записи:

- 📌 **закрепить** — закреплённые висят сверху и не удаляются при «Очистить»
  (и не вытесняются при переполнении);
- 📋 **копировать** исправленный текст в буфер;
- 📥 **вставить** в поле, которое было активным при открытии истории
  (через EWMH-активацию окна + Ctrl+V; зависит от настроек «кражи фокуса» KWin);
- ✕ **удалить** запись;
- **Очистить** — снести всё, кроме закреплённого.

Сверху — **поиск** (по тексту и приложению) и **группировка по приложению**.
Кнопка **Экспорт…** сохраняет историю в текстовый файл. В каждой строке видно
**приложение** (WM_CLASS), где сделана замена.

Хранится последние 100 незакреплённых записей (+ все закреплённые).

## Настройки (окно)

Меню трея → **Настройки…**. В окне:

- **Горячая клавиша** — кнопка «Изменить…», три варианта:
  - одиночная клавиша — `Pause`, `F12`, `Menu`;
  - модификатор(ы)+клавиша — `Ctrl+Space`, `Ctrl+Shift+Z`;
  - **два+ модификатора** — `Ctrl+Shift`, `Alt+Shift`: нажми их и отпусти.
    Срабатывает на отпускание и **только если между нажатием и отпусканием
    не было других клавиш** (через пассивный мониторинг XRecord), поэтому
    обычные `Ctrl+Shift+V`, `Ctrl+Shift+T` и т.п. не задевает.

  Для клавишных хоткеев при сохранении проверяется, что хоткей **не занят**
  системой/другим приложением (X-grab `BadAccess`); если занят — показывается,
  каким именно KDE-шорткатом (парсинг `kglobalshortcutsrc`).
- галочки: включён / уведомления / переключать раскладку после исправления /
  бейдж (+ «у каретки») / **запускать при входе в систему** (тумблер автозапуска);
- **Исключения** — слова, которые не исправлять (по одному на строку);
- **Не работать в приложениях** — подстроки `WM_CLASS` (свитчер выключен в них;
  узнать класс приложения можно по списку «Известные» — берётся из истории);
- живая проверка транслитерации (печатаешь — сразу видишь результат).

Кнопка «Сохранить» применяет всё на лету (перехватывает новый хоткей,
пишет `config.json`) — перезапуск не нужен.

> ℹ️ Поля паролей на X11 надёжно не детектируются — для них используй
> «Не работать в приложениях» (добавь нужное приложение).

## Статистика

Меню трея → **Статистика…**: сколько было переключений раскладки и исправлений
(всего и сегодня), топ самых частых исправленных слов. Кнопка «Сбросить».
Хранится в `~/.config/punto-switcher/stats.json`.

Настройки также лежат в `~/.config/punto-switcher/config.json`
(`hotkey`, `notify`, `switch_layout_after_fix`) — можно править вручную,
тогда перезапусти демон.

## Управление

```bash
# логи
tail -f /tmp/linux-punto.log

# остановить
pkill -f punto.py

# запустить вручную (для отладки — пишет в консоль)
python3 punto.py

# убрать автозапуск
rm ~/.config/autostart/linux-punto.desktop
```

## Как это работает

- **Хоткей-клавиша**: `XGrabKey` через `ctypes` → `libX11` (перехват клавиши
  глобально, со всеми комбинациями Caps/Num Lock).
- **Хоткей из модификаторов** (`Ctrl+Shift`): пассивный мониторинг всех
  нажатий через **XRecord** (`libXtst`) + детектор «чистого аккорда» —
  срабатывает на отпускание, если между нажатием и отпусканием не было
  посторонних клавиш. Так не ломаются обычные `Ctrl+Shift+…` сочетания.
- **Выделение vs. раскладка** (неразрушающе, без синтетических нажатий):
  сначала спрашиваем через **AT-SPI** у сфокусированного поля, есть ли
  выделение и какое (Qt/GTK/браузеры). Где AT-SPI недоступен (терминалы и пр.) —
  читаем **PRIMARY-выделение X11** и проверяем, что его владелец — активное
  окно (отсекает старое выделение из другого приложения). Никакого `Ctrl+C`:
  иначе в терминал улетал бы SIGINT, а в Kate копировалась бы целая строка.
- **Замена текста**: исправленный текст кладётся в буфер и вставляется
  `Ctrl+V`; исходный буфер обмена восстанавливается.
- **Раскладка**: `org.kde.KeyboardLayouts.switchToNextLayout` по D-Bus.

## Ограничения

- Только **X11** (на Wayland `XGrabKey`/`XTEST` не работают).
- В **терминалах** `Ctrl+C`/`Ctrl+V` — это не копирование/вставка
  (там `Ctrl+Shift+C/V`), поэтому исправление выделения в терминале не
  сработает. Переключение раскладки работает везде.
- Клавиша **Pause** не должна быть занята другим глобальным шорткатом KDE.
